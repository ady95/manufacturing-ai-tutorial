# 13장 결과 파일

`13_examples.png`, `13_heatmaps.png`에는 MVTec AD 이미지가 들어 있습니다.

`13_runs_book/`은 책에 실린 13장 실측 결과(카테고리별 PatchCore·기준 모델 점수, bottle·screw·carpet 이상 지도)입니다. 14장 Notebook과 재검토 화면이 13장을 직접 실행하지 않았을 때 이 결과를 씁니다. 13장 Notebook을 실행하면 `13_runs/`에 새 결과가 생기고, 14장은 그쪽을 먼저 씁니다. 이 폴더의 파일도 MVTec AD에서 계산한 결과이므로 아래 조건을 따릅니다.

- 출처: Bergmann et al., "MVTec AD — A Comprehensive Real-World Dataset for Unsupervised Anomaly Detection", CVPR 2019 (MVTec Software GmbH)
- 라이선스: CC BY-NC-SA 4.0. 비상업적 목적으로만 사용할 수 있고, 변경·재배포 시 같은 조건을 적용해야 합니다.
