# 실험 기록 — PoC 1. SECOM 불량 위험 예측

책 4~6장. 결과 파일: `01-yield-risk/results/04_eda.json`, `05_models.json`, `06_threshold_shap.json`

## 1. 연구 질문

- 공정 센서 특성 590개로 제품의 불량(Fail) 위험을 순위 매길 수 있는가
- 바뀌는 행동: 위험 상위 제품을 추가 검사로 보냄
- 비교 대상: 알람 없음, 전수 재검사, 입력을 보지 않는 기준 모델(Dummy)

## 2. 데이터셋

| 항목 | 내용 |
|---|---|
| 출처 | UCI Machine Learning Repository, SECOM (dataset 179) |
| 크기 | 1,567건 × 특성 590개 |
| 정답 | Pass/Fail (Fail 104건, 6.64%). 수율(%) 값은 없음 |
| 품질 문제 | 결측 셀 다수, 상수 특성, 중복 특성, 심한 불균형 |

## 3. 데이터 분리

| 항목 | 내용 |
|---|---|
| 분리 기준 | 타임스탬프 순. 앞 80% 개발, 뒤 20% 평가 |
| 개발 / 평가 | 1,253건(Fail 87) / 314건(Fail 17) |
| 개발 내 검증 | 시간 순 확장 교차검증 3겹(검증 블록 250~251건) |
| 누수 방지 | 결측 대체·스케일링·특성 선택을 모두 Pipeline 안에서 학습 데이터로만 적합 |
| 누수 시연 | 분리 전 특성 선택 PR-AUC 0.236 vs 파이프라인 안 0.186 (개발 데이터 무작위 5겹) |

## 4. 모델

| 구분 | 모델 | 설정을 정한 방법 |
|---|---|---|
| 기준 | Dummy(prior), Logistic Regression | 고정 |
| 비교 | LR + SelectKBest(k=80, C=0.1) | 시간 CV 격자 탐색 |
| 비교 | Random Forest, XGBoost, LightGBM | 기본 설정 |
| 비교 | XGBoost (Optuna 40회) | 시간 CV, 120.5초 |

## 5. 결과 (평가 PR-AUC, 불량률 0.054)

| 모델 | 시간 CV | 평가 |
|---|---:|---:|
| Logistic Regression | 0.064 | 0.167 |
| LR + KBest | 0.127 | 0.135 |
| Random Forest | 0.047 | 0.081 |
| XGBoost (기본) | 0.092 | 0.087 |
| XGBoost (Optuna) | 0.153 | 0.070 |

## 6. 오류 사례와 예상 밖 결과

- 무작위 CV는 트리 모델 점수를 평가 대비 2.4~3.2배 부풀림
- 시간 CV 1위(Optuna XGBoost)가 평가에서 기본 설정보다 낮음 — 검증 블록 과적합
- 평가 불량 17건뿐이라 신뢰구간이 넓음

## 7. 해석과 한계

- 복잡한 모델이 단순한 모델보다 낫다는 증거 없음
- SHAP 결과는 예측 기여이지 불량 원인이 아님
- 비용 분석은 가정값 시뮬레이션
