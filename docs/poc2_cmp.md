# 실험 기록 — PoC 2. CMP 가상계측

책 7~10장. 결과 파일: `02-virtual-metrology/results/07_eda.json`, `08_models.json`, `09_reliability.json`, `10_deep.json`, `10_deep_colab_t4.json`

## 1. 연구 질문

- 연마 중 센서 기록으로 웨이퍼·공정 단계별 평균 제거율(AVG_REMOVAL_RATE)을 추정할 수 있는가
- 바뀌는 행동: 계측하지 않은 웨이퍼의 추정값 제공, 의심 웨이퍼만 실측으로 보냄
- 비교 대상: 공정 그룹 평균, 시각 kNN, 직전 실측값

## 2. 데이터셋

| 항목 | 내용 |
|---|---|
| 출처 | PHM Society 2016 Data Challenge. 원본 링크가 끊겨 Wayback Machine 보존본 사용, sha256 확인 |
| 크기 | 키(WAFER_ID, STAGE) 기준 training 1,981 / validation 424 / test 424 |
| 정답 | 평균 제거율. 공정 그룹(A123, A456, B)별 수준 차이가 큼 |
| 품질 문제 | 빈 CSV 파일, 제거율 1000 초과 이상값 4건, 기록 길이 편차 |
| 이용 조건 | 원본 페이지에 명시 없음. 학습 목적으로 출처 표기 |

## 3. 데이터 분리

| 항목 | 내용 |
|---|---|
| 공식 분리 | training(이상값 4건 제외 1,977) 학습, validation+test 848건 평가 |
| 개발 내 검증 | WAFER_ID 기준 GroupKFold 5겹(shuffle, 시드 42) |
| 시각 순 재분리 | 전체 2,825건 중 앞 40%(1,130건) 학습, 나머지 운영 스트림 |
| 누수 위험 | 공식 분리는 같은 기간에서 섞여 뽑힘. 웨이퍼 겹침 train-val 115, train-test 113 |

## 4. 모델

| 구분 | 모델 |
|---|---|
| 기준 | 그룹 평균, 시각 kNN(k=10) |
| 선형 | RidgeCV, Ridge(그룹별), PLS(1% 규칙으로 20성분) |
| 트리 | Random Forest(500), XGBoost(600), XGBoost Optuna 40회(361초) |
| 딥러닝 | LSTM, TCN (시드 42·43·44) |

## 5. 결과 (공식 평가 848건 MAE)

| 모델 | 평가 MAE |
|---|---:|
| 그룹 평균 | 5.827 (전체 R² 0.935) |
| Ridge | 4.275 |
| PLS | 4.283 |
| Random Forest | 2.497 |
| XGBoost | 2.529 (Colab 2.595) |
| XGBoost Optuna | 2.391 |
| 시각 kNN | 2.127 |
| TCN | 2.906 (Colab T4 2.959) |
| LSTM | 3.215 (Colab T4 3.225) |

- 예측구간 90% 포함률: conformal 0.906, quantile 0.542, CQR 0.907
- 시각 순 운영 기간: XGBoost MAE 8.172, 90% 구간 포함률 0.319
- 실측 5% + EWMA 보정: XGBoost 4.270, 그룹 평균 4.246

## 6. 오류 사례와 예상 밖 결과

- 그룹 평균만으로 전체 R² 0.935 — 전체 R²는 그룹 차이만 반영
- 그룹별 Ridge가 학습 범위 밖(기록 14,678행) 웨이퍼에 음수 예측
- 중요 특징인 드레서 테이블 사용량이 시각과 상관 0.999 — 모델이 시계 역할의 카운터를 사용
- XGBoost 결과가 스레드 수에 따라 2.529~2.587로 달라짐

## 7. 해석과 한계

- 공식 분리 성능의 대부분은 센서가 아니라 시점 정보에서 옴
- 운영 기간에는 모델 단독으로 무너지고, 표본 실측 + 보정이 오차를 줄임
- 65일 데이터로 소모품 교체 주기를 충분히 담지 못했을 수 있음
